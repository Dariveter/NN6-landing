# Перенос в Тильду

Подготовлены файлы для всех трёх страниц: главной, выпускников и отзывов. Сам сайт в аккаунт Тильды в рамках передачи не переносился.

## Вариант 1 — редактировать дизайн в Zero Block

Файлы:
- `tilda/zero-block/index-inline-css.html`
- `tilda/zero-block/alumni-inline-css.html`
- `tilda/zero-block/reviews-inline-css.html`

В этих копиях CSS включён в HTML, а изображения и шрифты используют абсолютные адреса действующей публичной версии.

В Zero Block откройте меню с тремя точками → **Import from HTML**, загрузите нужный файл, затем **Prepare to Import**. Можно выбрать отдельный раздел и проверить его на нужных размерах экрана. После импорта проверьте структуру групп, шрифты, переносы, кнопки и мобильную версию.

По документации Тильды HTML-импорт не переносит JavaScript; его добавляют отдельно через T123. Источник: [Import from an HTML File](https://help.tilda.cc/zero/import-methods/html-file-import).

**Для нашего проекта это означает:** оформление можно использовать как исходную точку. Календарь с фильтрами, раскрытия, модальные карточки, карусели, WebGL и Нейроний не превращаются автоматически в штатные интерактивные элементы Тильды. Их нужно заново подключить или собрать средствами Тильды. Нельзя обещать точный перенос всего сайта одной кнопкой.

Для поэтапной работы начинайте с одного блока. Эталон — текущий сайт и скриншоты в `docs/images/`. Тексты и ресурсы доступны независимо от импортера в `site/`.

## Вариант 2 — вставить работающий сайт через T123

Используйте фрагмент из `tilda/t123/index.html` или соответствующего файла для выпускников/отзывов. Это iframe с опубликованной страницей.

Создайте отдельную страницу, добавьте блок **T123 / HTML**, вставьте фрагмент и опубликуйте. Код проверяйте на опубликованной странице: Тильда не выполняет его как обычную страницу в редакторе. Источник: [Embed HTML Code](https://help.tilda.cc/html).

Этот вариант оставляет код и логику на исходном хостинге. Редактирование текста внутри iframe происходит в репозитории, а не через визуальный редактор Тильды. Выделите под него самостоятельную страницу без дополнительной шапки и подвала; высота iframe — один экран, прокрутка идёт внутри него. Проверьте это на телефоне.

Если нужен полноценный нативный лендинг на Тильде с собственным SEO и общей навигацией, используйте первый вариант и отдельную адаптацию взаимодействий.

## Перегенерировать файлы

После правок выполните из корня проекта:

```bash
npm run tilda
```

Если готовый сайт переехал на другой публичный адрес, передайте его через `--base-url`. Значение должно быть адресом опубликованного сайта со всеми файлами из `dist/`, с HTTPS.

Пример для текущей публикации:

```bash
npm run tilda -- --base-url https://nii-field-winter-v3.vercel.app/
```

Приватный GitHub не является публичным хранилищем изображений. При полном переезде перенесите изображения и шрифты в своё публичное хранилище/Тильду, затем обновите ссылки. Не отключайте прежний хостинг до замены этих адресов.

## Финальная приёмка в Тильде

- Главная, выпускники и отзывы связаны правильными ссылками.
- Цена относится ко всему сезону.
- Изображения и шрифты открываются без входа в аккаунт.
- Календарь, раскрытия и кнопки проверены после публикации.
- Нет двойной шапки и нежелательной вложенной прокрутки.
- Оплата и документы ведут на согласованные действующие страницы.
- Помощник отвечает по актуальной версии программы.

Проверка импорта внутри вашего аккаунта Тильды остаётся отдельным этапом: доступ к редактору в этой задаче не использовался.
