## Размеры

| Набор | Размер без сжатия |
|---|---:|
| HTML, два CSS, два сценария, три шрифта, логотип, favicon и desktop hero | 556.9 КиБ |
| Тот же набор с мобильным hero | 429.4 КиБ |
| Основные сценарии вместе | 10.9 КиБ |
| Hero desktop / mobile | 191.3 / 63.8 КиБ |
| Иллюстрация ментора, отложенная загрузка | 102.2 КиБ |

Это сумма размеров файлов, не измерение LCP и не полный сетевой водопад. Логотипы и портреты загружаются отложенно, но браузер может запросить часть заранее. PDF загружается только по ссылке. Видео открываются на YouTube, тяжёлые видеоплееры не встроены автоматически. Внешних исполняемых библиотек и счётчиков в прототипе нет.

## Исправлено по результатам проверки

- Динамические панели наследовали inline-отображение из прошлой версии; восстановлена правильная раскладка переключателей.
- Иллюстрация hero на 768 px выступала за область просмотра; её ширина скорректирована.
- Между месяцами и фильтром направления добавлен достаточный интервал.
- У трёх примеров появились разные схемы результата: диаграмма отчёта, мини-план публикаций, дайджест.
- При недоступности WebGL не запускается бесполезный цикл отрисовки.

## Границы проверки

Не проводились реальные платежи и выдача доступа; не измерены конверсия, Lighthouse, реальные LCP / INP / CLS, мобильная сеть и батарея. Нет полного WCAG-аудита и проверки экранным диктором. Не все 14 видео просмотрены заново целиком; ссылки взяты из банка доказательств. Внешние контакты не получали сообщений.
