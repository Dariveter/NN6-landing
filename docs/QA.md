# Проверка передачи в GitHub

Дата: 9 октября 2026. Эта проверка относится к упаковке проекта, не к изменению опубликованного дизайна.

- 59 файлов текущего сайта побайтно совпадают с переданной v4.6.
- Сборка и экспорт для Тильды выполнены в отдельной временной копии, запущенной из другой рабочей папки. Привязки к исходной папке Obsidian нет.
- 3 страницы и 275 локальных ссылок/ссылок на ресурсы прошли проверку.
- Синтаксис актуального JavaScript проверен.
- 54 проверки Нейрония прошли; платная модель в проверках отключена.
- Проверена загрузка обёртки серверной функции Vercel.
- В локальном браузере открыта версия из новой папки: иллюстрации загрузились, фильтр «Стратегия» выбрал ноябрьское событие, Нейроний ответил о CEO НИИ. Ошибок JavaScript в просмотренном журнале нет.
- Подготовлены три HTML со встроенным CSS и три iframe-фрагмента. В вариантах Zero Block нет скриптов и относительных ссылок на локальные изображения.

- Приватный статус целевого репозитория подтверждён через GitHub перед загрузкой.

Машинные отчёты: [transfer-checks.json](transfer-checks.json), [portable-check.json](portable-check.json). Состав первичного копирования: [import-manifest.json](import-manifest.json).

## Границы

Сайт на действующем Vercel не менялся при передаче. Новый Vercel-проект и публикация внутри Тильды не выполнялись. Не проверялись реальные платежи, отправка приглашений, физические мобильные устройства или реальные пользовательские показатели скорости.

Визуальный аудит v4.6 и его ограничения сохранены в `history/deliverables/готовое/Аудит-и-правки-v4.6.md`.

## Что повторять после правок

Из корня проекта запустите `npm test` и `npm run build`, затем откройте `npm start`. Проверьте основной и выпускной тарифы, календарь, одну карточку эксперта, отзыв, ответ Нейрония и переход к оплате. При изменении контента обновляйте базу помощника.
