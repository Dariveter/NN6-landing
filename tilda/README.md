# Файлы для Тильды

Инструкция: [../docs/TILDA.md](../docs/TILDA.md).

- `zero-block/` — самостоятельные HTML со встроенным CSS для импорта дизайна; без JavaScript.
- `t123/` — фрагменты iframe для уже опубликованного работающего сайта.
- `manifest.json` — исходные страницы и используемый публичный адрес ресурсов.

После изменения `site/` выполните `npm run tilda`. Сгенерированные файлы включены в Git, чтобы дизайнер мог скачать их без запуска команд.
