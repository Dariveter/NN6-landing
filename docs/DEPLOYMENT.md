# Публикация

## Обычный статический хостинг

Из корня репозитория выполните:

```bash
npm run build
```

Загрузите **содержимое `dist/`** в публичную папку сайта. Сохраните структуру `assets/` и имена `index.html`, `alumni.html`, `reviews.html`.

Не публикуйте корень репозитория: `history/` и `docs/` содержат внутренние рабочие материалы.

Без серверного обработчика Нейроний использует браузерный справочник. Запрос проверки `/api/neuroniy` на чистом статическом хостинге может вернуть 404; клиент после этого остаётся в справочном режиме. Платная модель не нужна.

## Vercel

Подготовлен `vercel.json`:
- Build command: `node scripts/build.mjs`
- Output directory: `dist`
- Framework preset: Other / без фреймворка
- Необязательная функция: `api/neuroniy.js`

В Vercel создайте новый проект или подключите существующий после проверки владельца и домена. Импортируйте приватный репозиторий `deygenson/NN6-landing`; при необходимости выдайте Vercel доступ именно к нему. Root Directory — корень репозитория. Сначала сделайте preview и проверьте все три страницы.

Копии `.vercel/project.json`, токенов и существующих настроек аккаунта сюда не переносились. Это позволяет коллеге подключить свой проект без использования чужих доступов. Автоматическая связь этого репозитория с текущим production не настраивалась.

Официальные справки: [конфигурация](https://vercel.com/docs/project-configuration), [Node.js functions](https://vercel.com/docs/functions/runtimes/node-js).

## Перед новым доменом

1. В трёх HTML-файлах замените адреса canonical, og:url, og:image и twitter:image на новый адрес.
2. Решите, должен ли сайт индексироваться. Текущая v4.6 содержит noindex.
3. Проверьте оплату, тарифы выпускников, документы, Telegram и видео.
4. Пересоберите материалы Тильды с новым публичным адресом, если их используете.
5. Проверьте регистрацию и письмо после реального платежа силами владельца платёжной системы.

Платёжные аккаунты, Тильда, домены и почтовая автоматизация живут вне этого репозитория.

## Режим Нейрония

В обычной конфигурации нужен только справочник. `NEURONIY_ENABLED=false` — безопасное значение по умолчанию. В репозитории нет ключей.

Опциональный серверный код сохранён для полноты проекта, но включение платной модели, лимитов и расходов — отдельное согласованное действие. Не включайте её только ради того, чтобы проверить внешний вид сайта.
