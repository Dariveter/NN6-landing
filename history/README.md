# История проекта

Здесь сохранены материалы предыдущих итераций, включая код, анализ, исходные изображения, скриншоты и готовые архивы.

**Рабочая версия находится в ../site/.** Не публикуйте всю эту папку как сайт.

- `project/` — копия исходной папки HANDOFF проекта лендинга.
- `deliverables/` — выпущенные материалы FIELD-дизайн-v4.
- `handoffs/` — отчёты о предыдущих этапах.

Исторические документы могут содержать отменённые формулировки, старые цены/названия, неудачные технические снимки и локальные пути прежнего компьютера. Они сохранены для истории, а не как новые инструкции или утверждённые условия.

Некоторые старые сборочные скрипты требуют сторонних библиотек и исходных локальных путей. Для текущей версии используйте команды из корневого README.
