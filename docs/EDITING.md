## Изображения и фирменный стиль

Все используемые файлы находятся в `site/assets/`. Основной визуал — `hero-v4.webp`, облегчённая версия — `hero-v4-small.webp`. Иллюстрации форматов имеют префикс `format-`, направлений — `route-`. Фото экспертов — чёрно-белые файлы `*-bw.webp` (Иоганна — `johanna-v4-5-bw.webp`, Юрий — `yuri-bw.webp`).

Исходные PNG и промпты генерации сохранены в `history/project/outputs/рабочее/`. Используйте оригиналы для новой обработки, а в сайт возвращайте оптимизированные изображения. Отдельные исходные файлы из сообщений — в `docs/sources/`.

## Порядок изменения контента

1. Правьте соответствующий блок `index.html`.
3. Для истории участника обновите также `reviews.html`, если материал присутствует там.
4. Обновите соответствующий документ/ответ в `neuroniy-knowledge-v4-6.json`. База помощника не считывает изменённый HTML автоматически.
5. Запустите `npm test` и `npm run build`.
6. Посмотрите страницу на телефоне и компьютере. После изменения программы расширьте тесты под новые факты.
